## 2. 审计范围与方法

本报告以仓库内保存的原始来源、目标证据、审计台账和自动校验结果为依据。核验方法包括：

1. 对来源文件记录抓取时间、最终地址、媒体类型、字节数和 SHA-256（安全哈希算法）；
2. 对网页与文档执行格式签名、保存路径、哈希和来源域名校验；
3. 将旧复合摘要拆为可独立定位、复核和评测的原子声明；
4. 逐条检查锚文本、逐字原文、规范化声明、适用对象、时间条件和版本标签；
5. 对 HTML（网页文件）和 PDF（便携式文档格式）来源重新提取文本并验证抽样锚点；
6. 对 PNG（便携式网络图形）图片、Word（文字处理）旧格式附件和 Excel（电子表格）旧格式附件进行只读打开、转换与整页渲染检查；
7. 使用正例、模式反例和来源外键反例验证校验器能够同时接受合法数据并拒绝非法数据。

## 6. 候选事项普查

候选事项普查表位于 `data/research/candidate-item-survey.csv`。评分范围为 0 至 3，分别记录证据完整度、条件分支、版本风险、评测价值和标注成本。

评分口径：

- 证据完整度：0 表示只有事项线索，3 表示来源快照、原子证据和迁移审计齐备；
- 条件分支：0 表示基本无条件分支，3 表示同时具有对象、时间、材料、例外或后果等多类分支；
- 版本风险：0 表示版本边界明确且稳定，3 表示存在多版本、限时通知、动态事实或真实差异；
- 评测价值：0 表示与核心研究变量关联弱，3 表示能够直接检验对象、版本、步骤或证据约束；
- 标注成本：0 表示单一来源和短流程，3 表示需要多来源、跨版本和复杂条件的独立复核。

## 8. 剩余风险与阶段边界

- 多个官方页面没有声明明确生效区间或版本替代关系，后续证据继续按页面版本分别记录。
- 地点、费用、联系方式和办理窗口具有变化风险，进入评测冻结或真实服务前需要按数据版本重新核验。
- 旧运行数据仍包含已知错误摘要；阶段 3 的加载器切换必须先建立旧、新结构行为对照和接口回归测试。
