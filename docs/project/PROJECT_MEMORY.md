## 4. 关键技术决策

- 正式项目名称保持不变。
- 当前候选研究问题是流程结构、条件槽位和证据绑定能否降低对象、版本、步骤和无证据断言错误；该问题尚待数据与实验验证。
- 第一实施阶段聚焦来源与证据，不先更换框架或增加复杂模型。
- 原始来源、规范化证据、流程结构和评测样本必须分层保存。
- 一个来源记录只对应一个能够独立保存并计算哈希的文件；落地页与附件必须使用不同来源编号并建立关系。
- 旧运行数据和目标数据契约暂时并存；阶段 3 在旧、新行为对照和接口回归测试通过后切换加载器。
- 旧错误摘要保留在原数据与审计台账中；修正内容写入目标证据，通过 `target_evidence_ids` 保存一对一或一对多迁移关系。
- 复合声明按可独立定位和评测的事实拆成原子证据。
- 流程性声明分别记录办理主体、动作、时限、例外和后果，时限只绑定原文明确约束的步骤。
- 对象范围不得越过承载原文的页面章节；地点、费用、账号和联系方式等易变信息必须绑定页面更新时间、快照日期和空的统一生效起止日期。
- 跨版本条件分别绑定来源版本；来源没有声明替代关系时，不合并为统一现行规则。
- 失效来源保留响应状态和失败原因，错误响应不作为证据；替代内容引用实际承载原文的同机构来源。
- 任何回答声明都应能够绑定本次实际检索到的证据。
- 实验必须记录数据版本、配置、随机种子、模型版本、原始输出、指标、耗时和费用。
- 阶段 2 正式覆盖 8 类事项、200 条冻结评测样本和 100% 第二次独立复核；毕业实习办理为跨事项迁移评测候选。
- 8 类事项等额分配 25 条样本，范围与配额已冻结；内容冻结必须满足完整标注、证据绑定、全量独立复核、全部分歧裁决和泄漏检查。
